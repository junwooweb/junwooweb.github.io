# 프로필 사진 폴더

Junwoo Kim 프로필에 표시할 사진을 **이 폴더에 넣으세요.**

- 지원 형식: `.jpg`, `.jpeg`, `.png`, `.webp`, `.avif`, `.gif`
- 표시 순서는 파일명 순서입니다. `01-main.png`, `02-conference.jpg`, `03-lab.webp`처럼 앞에 숫자를 붙이면 편합니다.
- 첫 번째 파일이 홈페이지에서 처음 보이는 사진입니다. 현재 사진은 `01-main.png`입니다.
- 사진이 두 장 이상이면 이전·다음 버튼과 현재 사진 번호가 나타납니다. 사진을 누른 확대 화면에서도 넘길 수 있습니다.
- 사진은 자동으로 넘어가지 않습니다. 버튼, 좌우 방향키, 휴대폰의 좌우 스와이프로 넘깁니다.
- 프로필에서는 원형으로 표시되고, 확대 화면에서는 사진 전체가 원래 비율로 표시됩니다.
- 이 안내 파일은 사진 목록에 포함되지 않습니다.

로컬 미리보기(`npm start`) 실행 중 사진을 추가·교체·삭제하면 사진 목록이 다시 생성됩니다. 브라우저를 새로고침해 확인하세요.

공개 홈페이지에는 프로젝트 루트에서 `npm run build` 후 사진과 생성된 `index.html`을 함께 커밋·push하면 반영됩니다. Codex에 “프로필 폴더 사진 반영해줘”라고 요청해도 됩니다. 폴더에 넣는 것만으로 인터넷에 업로드되지는 않습니다.
