Run `npm run build` after editing source files, then `npm run check` to verify the generated pages and links.

The homepage's scrollable Research Updates list includes accepted/published papers from `data/publications.json` and patent announcements from `data/research-updates.json`. Submitted manuscripts from `data/ongoing.json` appear separately under Ongoing Work. Paper status and author roles come from those records; `venueDisplay` can override an abbreviated venue label. `data/research-updates.json` supplies dates with their available precision: publication years, journal issue periods, or conference dates, rather than inferred acceptance dates. Undated patent filings appear first, followed by dated entries from newest to oldest; year-only dates appear first within their year. Conference papers, journal papers, and patent applications have full-height violet, teal, and amber labels. First-author roles remain highlighted; patent roles are omitted. Edit the template in `templates/home.html` and styles in `assets/publication-tools.css`, then commit the generated HTML together with the sources.
